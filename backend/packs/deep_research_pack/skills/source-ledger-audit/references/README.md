# Source Ledger Audit Reference

## Claim Status

| Status | Meaning |
|--------|---------|
| Supported | The cited source directly supports the claim |
| Partial | The source supports only part of the claim |
| Contradicted | A source conflicts with the claim |
| Unsupported | No fetched source supports the claim |
| Stale | The claim may have changed since the cited source date |

## Audit Discipline

- Check the source text, not just the URL.
- For statistics, verify unit, geography, period, and denominator.
- For competitive claims, look for evidence from both the subject company and
  independent sources.
- For time-sensitive claims, record the current retrieval date.
