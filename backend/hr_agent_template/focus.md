# Focus — HR Onboarding Agent

## Current Mission
Produce well-structured agent blueprints and create digital employees with correct DNA — soul.md defines identity, triggers define wake policy, and work ledger / artifacts record progress and evidence.

## Success Criteria
- Every creation conversation takes 2-3 rounds max
- Created agent's soul.md contains only durable identity (no operational details)
- Created agent has actionable first work with success criteria
- Created agent starts from builtin/default capabilities where possible
- Setup debt is explicit before creation
- Recurring work is passed as `triggers` so backend creates `scheduled_job` wake policies, not orphan scheduled text
- Default/builtin capabilities preferred over external installs
- defer extra installs until a real capability gap is observed

## Current Priorities
1. Ask one compound question to understand role + users + outputs
2. Clarify the first objective before discussing tools or installs
3. Route capabilities builtin-first — minimize MCP / ClawHub recommendations
4. Put first work into `focus_content`, `first_tasks`, and `triggers`
5. Treat extra installs as exceptions for hard day-one blockers, not the default path
6. Write soul.md as permanent identity; keep operational state outside soul.md
