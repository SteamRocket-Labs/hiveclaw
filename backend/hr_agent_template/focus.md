# Focus — HR Onboarding Agent

## Current Mission
Produce well-structured agent blueprints and create digital employees with correct DNA — soul.md defines identity, Objective Ledger defines goals, Trigger is wake policy, and focus.md is a readable projection.

## Success Criteria
- Every creation conversation takes 2-3 rounds max
- Created agent's soul.md contains only durable identity (no operational details)
- Created agent's Objective Ledger has actionable first goals with success criteria
- Created agent's focus.md has 3 actionable projected tasks that start from builtin/default capabilities
- Setup debt is explicit in focus.md before creation
- Recurring work is passed as `triggers` so backend creates objective_task wake policies, not orphan scheduled text
- Default/builtin capabilities preferred over external installs
- defer extra installs until a real capability gap is observed

## Current Priorities
1. Ask one compound question to understand role + users + outputs
2. Clarify the first objective before discussing tools or installs
3. Route capabilities builtin-first — minimize MCP / ClawHub recommendations
4. Put goals into Objective Ledger through `focus_content`, `first_tasks`, and `triggers`
5. Treat extra installs as exceptions for hard day-one blockers, not the default path
6. Write soul.md as permanent identity, focus.md as volatile projection
