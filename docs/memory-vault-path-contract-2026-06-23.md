# Memory Vault Path Contract

Status: current contract for the single-agent memory vault.

Hive memory has one mechanical truth and one semantic gradient:

```text
memory/
  t0/
    sessions/<session_id>/
      index.json
      segments/<segment_id>/
        events.jsonl
        source.md
  t2/
    sessions/<session_id>/
      segments/<segment_id>/
        summary.md
        labels.md
        review.md
        manifest.json
      episodes/<episode_id>/
        synthesis.md
        review.md
        manifest.json
  session_state/<session_id>/
    session_memory.md
  explicit/
    MEMORY.md
    manifest.jsonl
    entries/<explicit_id>.md
  t3/
    episodes.md
    user.md
    worker.md
    capabilities.md
  wiki/
    <concept>.md                  # derived/compat concept read-model pages
  scenes/
    <scene>.md                    # derived/compat episodic read-model pages
  indexes/
    wiki_map.md
  control/
    lifecycle.json
    lifecycle_maintenance.json
    auto_dream_state.json
  archive.md
  understandings.md                # optional read-only legacy relationship projection
  charter_calibration.md
  distillation_audit.jsonl
  reflections/
    <reflection_id>.jsonl
  retired_artifacts/
    ...                           # reversible quarantine for dead legacy files
  .staging/
    t2_jobs/

    logs_imports/                 # old logs/YYYY-MM-DD imports, not runtime T0

```

## Meanings

- `memory/t0/**` is the source transcript ledger. `events.jsonl` is the mechanical truth for resume, replay, fork, rollback, and audit. `source.md` is only a deterministic readable projection.
- `memory/t2/**` is the canonical distilled evidence layer. Segment Packages and Episode Stitch Packages are LLM-authored candidates reviewed by Memory Gate and committed by Platform Gate.
- `memory/session_state/**` is hot session continuity for resume/compaction. It is not T2, not T3, and not semantic long-term memory.
- `memory/explicit/**` is the explicit overlay for direct user commands such as "remember this"; it is immediately activatable but still waits for T3 consolidation. `entries/<explicit_id>.md` is the per-entry truth, `manifest.jsonl` is the append-only entry state log, and `MEMORY.md` is the generated readable overlay index.
- `memory/t3/**` is the accepted Agent Markdown Wiki semantic layer.
- `memory/wiki/**` and `memory/scenes/**` are optional derived/compat read-model pages from the deprecated scene/wiki curator lane. They are rebuildable views, not accepted T3 truth, and are never default prompt memory.
- `memory/indexes/wiki_map.md` is a generated read model from T3. It is rebuildable and must not be treated as semantic truth.
- `memory/control/lifecycle.json` is platform control metadata: lifecycle status, access telemetry, supersession, conflict, revalidation, rollback/audit facts.
- `memory/control/lifecycle_maintenance.json` is the latest lifecycle upkeep report generated by Heartbeat/lifecycle maintenance.
- `memory/control/auto_dream_state.json` is Dream cadence/history control metadata. Legacy root `memory/auto_dream_state.json` is migrated here on read/write.
- `memory/archive.md` is reversible retired-memory evidence. It is not active recall.
- `memory/understandings.md` is an optional read-only legacy relationship projection. Runtime writes are disabled; new relationship memory must enter through T0/T2/T3.
- `memory/charter_calibration.md` is an audit surface for approved owner/company charter proposal applications to `soul.md`.
- `memory/distillation_audit.jsonl` records curation decisions, including held/rejected candidates where no durable semantic write happened.
- `memory/reflections/**` stores reportable failure/reflection artifacts only. It is source/audit evidence, not canonical T2 or accepted T3.
- `memory/retired_artifacts/**` stores reversible quarantine copies of legacy shadow stores and dead stubs moved by memory hygiene.
- `memory/.staging/**` holds job artifacts before Platform Gate commits. It is not a durable semantic layer.
- `memory/.staging/dream_workspace/**` is the Memory Dream working surface: raw T2 inputs, rollout summaries, diff, and baseline for T2/T2.5 -> T3 staging.
- `memory/.staging/dream_backups/**` is a bounded backup surface for pre-consolidation Dream inputs. It is operational evidence, not semantic truth.
- `memory/.rollback/soul/**` stores pre-commit soul snapshots for exact rollback of accepted Soul Dream promotions.
- `memory/legacy/learnings` and `memory/legacy/logs_imports` are not normal output folders. They exist only when an operator/migration job quarantines old `memory/learnings/**` or `logs/YYYY-MM-DD/**` evidence so it can be re-imported into T0/T2 without pretending to be current truth.

## Ordering

- T0 is ordered by `index.json` and event `sequence`; segment ids are stable turn/checkpoint anchors.
- T2 is grouped by `session_id`, then ordered by the source T0 segment sequence recorded in `manifest.json`.
- T2 episodes are grouped under the same `session_id` and reference source Segment Packages in `manifest.json`.
- T3 has a fixed file order: `episodes.md`, `user.md`, `worker.md`, `capabilities.md`.
- `indexes/wiki_map.md` and `control/lifecycle.json` are sidecars/read models; they do not define semantic ordering by themselves.

## Compatibility

Runtime writes must use the canonical paths above. The code may still read legacy `memory/sessions/**`, root `memory/learnings/**`, root `memory/lifecycle.json`, root `memory/auto_dream_state.json`, root `memory/.curation_cursor.json`, root `memory/understandings.md`, old `runtime_artifacts/session_memory.md`, old `workspace/session_memory.md`, and old root `memory/wiki_map.md` only for migration or compatibility. Root `memory/learnings/**` may only be produced by explicitly enabled operator legacy replay/backfill; it must not be runtime T2, prompt memory, Heartbeat input, or T3 primary input. New normal writes must not recreate those legacy paths.
